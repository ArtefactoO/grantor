# Engine icons

SVG filenames match engine keys: `postgres.svg`, `mongodb.svg`, `mysql.svg`, `rabbitmq.svg`, `clickhouse.svg`, `kafka.svg` and `redis.svg`. EngineBadge loads them automatically at build time and uses a Lucide fallback when no asset exists.

Use a square viewBox without fixed root width/height. The component renders each SVG as a CSS mask using currentColor.

The current paths come from [Simple Icons](https://simpleicons.org/), distributed under CC0-1.0. Product names and logos may be trademarks of their respective owners and are used to identify connection types. Check the relevant brand guidelines before adding or replacing a mark.
