# Security

Please do not disclose credentials, private endpoints or exploitable vulnerabilities in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use **Security → Report a vulnerability**. Otherwise, agree on a private reporting channel with the maintainer before sharing details.

For a report, include the affected revision, a minimal reproduction with disposable data, impact and any proposed mitigation. There is no promised response or fix timeline.

The example environments and recorded demonstrations use local development credentials or synthetic fixtures. Replace development settings before exposing a deployment to other users.
